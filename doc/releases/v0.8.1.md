# v0.8.1

## What changed

- Corrected macOS portability for persistent path-injection state identity
  checks, whose native `stat` device field has a different integer type than
  Linux.
- Removed a macOS-only unused-process-stream import from the command
  supervisor.
- Carries the v0.8.0 feature release: bounded session-aware guidance, policy
  metadata and doctor guidance, workspace-scoped coverage, bounded command
  execution, workspace cwd containment, bounded current-task evidence, and
  structural TypeScript/JavaScript script discovery.

This is the first passing cross-platform release for the feature set prepared
under the immutable `v0.8.0` tag. That tag did not publish because its macOS
compile gate failed; it was not moved or force-updated.

## Affected users

- macOS users can use the persistent path-injection state checks in the
  published binary.
- Existing repositories with invalid policy, coverage, command, or workspace
  settings may receive explicit unverified results and repair guidance.

## Upgrade and compatibility

No configuration migration is required:

```sh
lgtm update
lgtm doctor
```
