# v0.8.7

## What changed

- Scoped Linux-only command-containment integration fixtures to Linux while
  retaining compiled and runtime coverage for honest unavailable behavior on
  macOS.
- Carries the v0.8.0 feature release and the cross-platform repairs from
  v0.8.1 through v0.8.6.

The immutable `v0.8.0` through `v0.8.6` tags remain preserved failed
attempts; no failed tag was moved or force-updated.

## Affected users

- macOS users receive honest unverified command evidence when production
  containment is unavailable.
- Existing repositories with invalid policy, coverage, command, or workspace
  settings may receive explicit unverified results and repair guidance.

## Upgrade and compatibility

No configuration migration is required:

```sh
lgtm update
lgtm doctor
```
