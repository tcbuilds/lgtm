# v0.8.9

## What changed

- Add `lgtm init -g` / `lgtm init --global` for machine-wide harness setup.
- Install and merge Claude Code hooks under `$HOME/.claude/settings.json`.
- Install all embedded Claude standards under `$HOME/.claude/rules/`.
- Install and merge Codex hooks under `$HOME/.codex/hooks.json`.
- Add the complete always-loaded LGTM standards entry to `$HOME/.codex/AGENTS.md`.
- Preserve unrelated user hooks and instruction text, update only LGTM-managed content, and make repeat runs idempotent.
- Add `--dry-run` support so global writes can be reviewed before mutation.

## Affected users

Users can run global initialization from any working directory, including `$HOME`:

```sh
lgtm init -g --dry-run
lgtm init -g
```

Global init does not create repository `.lgtm` configuration. Run `lgtm init`
inside each repository that needs repository-specific commands, policy overrides,
or execpolicy settings. Codex users must review changed global command hooks through
`/hooks` because Codex manages hook trust separately.

## Upgrade and compatibility

No migration is required. Update the binary, then preview and apply the global
installation:

```sh
lgtm update
lgtm init -g --dry-run
lgtm init -g
```

Existing global settings and instruction text are preserved. Remove or edit only
the files you intentionally want to change.
