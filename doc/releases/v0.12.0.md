# v0.12.0

LGTM v0.12.0 adds scoped mobile design guidance based on Apple's Human Interface
Guidelines and Android's design guidance.

## Added

- `mobile-ui.md`: shared accessibility, adaptive layout, appearance, motion,
  loading, error, offline, and permission guidance.
- `ios-ui.md`: native navigation, Dynamic Type, VoiceOver, safe areas, and a
  44-point default touch target.
- `android-ui.md`: Material components, system/predictive Back, TalkBack,
  scalable text, insets, and touch targets of at least 48 dp.
- Claude installs the three frontmatter-scoped files. Pi selects their bodies
  from the embedded catalog. Codex includes their platform-conditional prose in
  its combined guidance document, with upgrades for unchanged v0.11.1 documents.

These are design instructions, not new enforcement checks or proof of platform
or accessibility compliance. Verify actual interfaces on devices or simulators.

## Scope

Mobile directory names and platform filename suffixes activate the guidance;
ordinary web, backend, and desktop language files do not. Shared React Native or
Flutter paths receive shared guidance, not an inferred active platform. Arbitrary
project layouts need explicit project guidance; see
[`templates/claude-rules/README.md`](../../templates/claude-rules/README.md#mobile-design-guidance)
for the exact limitations and customization options.

## Upgrade

Install v0.12.0, then refresh guidance with the installed binary:

```sh
# Claude guidance only
lgtm init --rules-only

# Pi: regenerate the extension, then restart Pi
lgtm init --agent pi

# Codex guidance only
lgtm init --agent codex --rules-only
```

Locally edited guidance is preserved. Pi uses the binary's embedded rules, not
edited copies under `.claude/rules/`. No evidence schema migration or new
dependencies are introduced.

## Validation

`cargo test --test mobile_guidance` covers the platform scope matrix, embedded
and installed source parity, guidance-only parsing, repeat installation, local
edit preservation, and unchanged pre-mobile Codex document upgrades.

The tag-triggered release workflow runs the full locked test suite and builds
Linux musl and Intel macOS binaries with checksums before publication.

## Rollback

Reinstall v0.11.1. For Pi, regenerate the extension with that binary and restart
Pi. For Claude, remove only the three new mobile rule files if no longer wanted;
older init does not remove them. For Codex, remove their sections from `AGENTS.md`
or restore your saved pre-upgrade document; older init preserves unknown content.
