# v0.8.4

## What changed

- Canonicalized Stop-hook test fixture roots so macOS `/var` aliases match
  canonical current-task paths.
- Scoped the same-process `flock` contention unit fixture to Linux while
  retaining persistent-store integration coverage on macOS.
- Carries the v0.8.0 feature release and the cross-platform repairs from
  v0.8.1, v0.8.2, and v0.8.3.

The immutable `v0.8.0`, `v0.8.1`, `v0.8.2`, and `v0.8.3` tags remain preserved
failed attempts; no failed tag was moved or force-updated.

## Affected users

- macOS users can use current-task evidence and persistent path-injection state
  without the previous release-matrix test failures.
- Existing repositories with invalid policy, coverage, command, or workspace
  settings may receive explicit unverified results and repair guidance.

## Upgrade and compatibility

No configuration migration is required:

```sh
lgtm update
lgtm doctor
```
