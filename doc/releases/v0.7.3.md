# v0.7.3

## What changed

- Stop now defaults to the `targeted` tier instead of running full repository
  tests, builds, and coverage whenever an agent yields control.
- Direct Claude Code and Codex `git commit` attempts run the `full` tier through
  PreToolUse. A failing gate denies the pending commit with repair details.
- Successful full evidence is reused on an unchanged retry and by later Stop
  claim checks only when the session, touched files, config, policy version, and
  binary version still match.
- Evidence records now include the tier that produced them. Existing records
  without this optional field remain readable.
- Explicit `lgtm check --tier full`, the optional pre-push hook, and CI remain
  full-gate backstops.

## Affected users

Claude Code and Codex users no longer pay for a full test suite on every Stop.
Agent-created commits still require current full-gate evidence when the shell
command is intercepted.

Direct command detection intentionally excludes nested shell indirection such
as `sh -c 'git commit ...'`. Human commits and unsupported agent paths should
keep the pre-push hook and CI enabled.

## Upgrade and compatibility

No configuration migration is required. Upgrade with:

```sh
lgtm update
```
