# v0.8.2

## What changed

- Fixed macOS portability for persistent path-injection state identity checks
  and directory durability handling.
- Kept command containment fail-closed in macOS production while allowing the
  unit suite to exercise bounded command behavior without claiming Linux-only
  containment.
- Scoped raw non-UTF-8 path and descriptor-containment fixtures to the
  platforms that support those guarantees.
- Carries the v0.8.0 feature release: bounded session-aware guidance, policy
  metadata and doctor guidance, workspace-scoped coverage, bounded command
  execution, workspace cwd containment, bounded current-task evidence, and
  structural TypeScript/JavaScript script discovery.

The immutable `v0.8.0` and `v0.8.1` tags remain preserved failed attempts; no
failed tag was moved or force-updated.

## Affected users

- macOS users receive the same published path-injection state behavior without
  the previous release-matrix test failures.
- Existing repositories with invalid policy, coverage, command, or workspace
  settings may receive explicit unverified results and repair guidance.

## Upgrade and compatibility

No configuration migration is required:

```sh
lgtm update
lgtm doctor
```
