# v0.7.2

## What changed

- Stop hooks now stay silent for chat-only sessions and other lifecycle events
  with no actionable edits or verification claims.
- Stop output is bounded and unsupported assets or configuration files no longer
  create long, non-actionable test-association reports.
- PostToolUse now records the edited file directly, so Stop evaluates the files
  changed in the current session instead of unrelated paths from prior evidence.
- Native Claude and Codex Stop hooks now apply the documented `full` tier when
  their payload omits `tier`. Applicable tests, builds, and coverage commands are
  no longer silently skipped at the final gate.
- Explicit `lgtm check --tier fast|targeted|full` selection remains exact.

## Affected users

This is a correctness and signal-quality release for all hook users. It removes
large false-positive lifecycle summaries while restoring the required full-tier
repository checks at Stop.

Stop may take longer when a touched workspace has full-tier commands. Commands
remain scoped to touched workspaces and retain their configured timeouts.

## Upgrade and compatibility

No configuration or evidence schema migration is required. Existing V2 command
tiers remain authoritative. Upgrade with:

```sh
lgtm update
```
