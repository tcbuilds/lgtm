# v0.8.0

## What changed

- Added bounded, session-aware guidance selection so the same policy source is
  not injected repeatedly during one session.
- Added policy metadata and doctor guidance for supported checks and relevant
  tooling.
- Added bounded path-injection guidance for supported repository files, with
  safe handling for malformed, oversized, symlinked, and non-regular inputs.
- Policy profile and override validation now fails closed with bounded,
  sanitized diagnostics.
- Coverage gates are workspace-scoped and honor configured line and branch
  thresholds without treating incomplete measurements as passes.
- Command execution now bounds aggregate work, contains descendants, rejects
  incomplete reusable evidence, and enforces workspace cwd containment.
- Module checks fail closed when supported inputs are incomplete.
- Current-task evidence retention is bounded and malformed or invalid ledgers
  remain explicitly unverified rather than silently passing.
- TypeScript and JavaScript script discovery reads configured scripts
  structurally instead of guessing from arbitrary names.

## Affected users

- Existing repositories with invalid policy, coverage, command, or workspace
  settings may now receive an explicit unverified result and repair guidance.
- Commands configured outside their workspace root are rejected rather than
  executed with an unproven cwd.
- Agents receive repeated matching guidance at most once per session.

## Upgrade and compatibility

No configuration migration is required. Review `lgtm doctor` output after
upgrading, and regenerate current-task evidence if it is reported as malformed
or incomplete:

```sh
lgtm update
lgtm doctor
```
