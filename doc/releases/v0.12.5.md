# v0.12.5

## Shell edits reach Stop

LGTM now tracks file changes around matched shell tool calls. Scripts, redirects,
file removal, renames, and executable-bit changes no longer depend on an Edit or
Write event to enter the session's touched-file list. Unchanged pre-existing
dirty files are not claimed.

The fix includes Pi Bash result routing and native call-ID propagation. Claude
receives Bash success and failure hooks. Managed refresh migrates the old Claude
matcher once and preserves later removal of the failure event.

Missing or mismatched events, overlapping calls, read limits, and unsupported
paths remain unverified. Outstanding calls cannot be forgotten by changing
sessions. Secret scans, fresh staged-commit assessment, and unrelated-change
checks remain enabled.

## Upgrade

Run `lgtm update`, then restart your agent. No package update is required for
this fix. Unregistered installations need one matching `lgtm init` registration.

See [How LGTM tracks shell changes](../shell-change-tracking.md) for limits,
interrupted-call recovery, verification commands, and rollback steps.

No new native Pi compatibility, approval UI, or codemode enforcement claim is
made by this release.
