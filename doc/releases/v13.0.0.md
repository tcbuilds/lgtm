# v13.0.0 — release preparation

This is the owner's target for the next release, not a published release.
The package version and tag must be updated together only after PR #126's
repairs, required checks, independent review, and merge are complete.

## Features

- Six advisory Jev tools for bounded file questions, diff-review flags, scope
  and claim advice, diagnostic triage, compaction advice, and untrusted-text
  warnings. They use Pi's native classifier API and existing provider auth.
- Managed Pi init includes these tools. Startup makes no classifier request;
  deterministic LGTM enforcement remains separate and authoritative.

## Breaking changes from the earlier PR drafts

- Inline request bodies are replaced by bounded workspace JSON files. Pass
  `requestPath`, not raw excerpts, rubrics, scope/claims, or compaction state.
- `preview` and `allowSend` belong only in outer arguments. A request body cannot
  grant transport permission. Diff review retains its empty argument object.
- Prepare private request files outside recorded tool arguments. Pi journals
  nested arguments before a tool runs; malformed inline calls can still be
  recorded even when Jev rejects them. File references cannot erase prior logs.

## Repairs included in the PR

- Use complete native structured Bash output and an independent NUL-delimited
  filename list with rename detection and text/external drivers disabled. Recheck paths after reading the patch; do not treat hunk bodies
  as filenames or truncated displays as complete diffs.
- Redact both source metadata and excerpts before preview, transport, return,
  and optional Jev metadata persistence. Reject private-key input and common
  private credential paths; handle quoted JSON credential assignments.
- Use bounded credential scanning instead of overlapping backtracking patterns;
  keep complete authorization schemes and tokens inside the redacted span.
- Consume governed read output only. Use metadata-only source previews and
  stability checks, reject redirected/missing read bindings, and bound request
  files to 32 KiB and 1,500 lines. Output hashes describe authorized read text.
- Accept valid fractional expected-index scores from the native classifier.
- Share repeated privacy/transport code, classify integration fixtures as tests,
  and measure real execution of the rendered JS fragments for SonarCloud LCOV.

## Verification and limits

Release readiness is not claimed by this preparation note. Final checks and
review must pass before publication. The earlier live replay is historical;
there is no new paid replay of the repaired reference-input API yet.

Redaction is a conservative heuristic, not proof that arbitrary text is safe.
Jev judgments never grant permission, verify a command claim, or change a gate.
Unsupported runtime APIs and provider failures remain explicit unavailable
outcomes. Native interactive approval UI is not validated by these Jev tests.

See [the Pi API and privacy guide](../adapters/pi.md#jev-advisory-tools-and-request-privacy)
for request formats, bounds, safe input preparation, and the migration path.
