# v0.8.3

## What changed

- Canonicalized the repository root before checking current-task files for
  containment, so macOS `/var` symlink aliases do not discard valid paths.
- Made macOS directory durability handling compatible with its directory
  descriptor behavior while retaining file sync before atomic state replacement.
- Carries the v0.8.0 feature release and the cross-platform test-matrix fixes
  from v0.8.1 and v0.8.2.

The immutable `v0.8.0`, `v0.8.1`, and `v0.8.2` tags remain preserved failed
attempts; no failed tag was moved or force-updated.

## Affected users

- macOS users can use current-task evidence and persistent path-injection state
  without the previous release-matrix failures.
- Existing repositories with invalid policy, coverage, command, or workspace
  settings may receive explicit unverified results and repair guidance.

## Upgrade and compatibility

No configuration migration is required:

```sh
lgtm update
lgtm doctor
```
